# Karryn's Prison Multiplayer

Version: 0.12.1.

Requires your own copy of the game. 

## Installation and usage

Close the game and back up the files being replaced. Copy `www` and the `KPMP_*.bat` launchers into the game folder containing `nw.exe`, allowing replacements.

Run `KPMP_HOST.bat` on the host and `KPMP_CLIENT.bat` for the joining player. `KPMP_LAUNCH_BOTH_LOCAL.bat` starts a local two-instance session. Both players need the same mod build.
